# English Quest 30 — เรียนภาษาอังกฤษ 30 วันแบบเกมผ่านด่าน

เว็บแอป (PWA) ติดตั้งลงมือถือได้ · ใช้งานออฟไลน์ได้ · 🌐 https://sarawut2206.github.io/AI2-/

## โครงสร้างเกม
- **4 โลก = 4 สัปดาห์ · 30 ด่าน = 30 วัน** ปลดล็อกทีละด่าน มีบอสท้ายโลก (ด่าน 7, 14, 21, 30)
- ทุกด่านทำตามรูปแบบ 50 นาที: 🔁 ทบทวน (สุ่มจากด่านก่อน + ข้อที่เคยผิด) → 📘 เข้าใจกฎ → 🧩 ภารกิจ → 🎙️ พูด → ✍️ เขียน
- 🔗 **ประโยคเชื่อมด่าน** — *The teacher checks the homework.* ถูกแปลงด้วยไวยากรณ์ใหม่ทุกด่าน (19 รูป) เพื่อให้เห็นว่า 15 หัวข้อเชื่อมกัน
- ⭐ ดาว 1–3 ตามความแม่นยำ (ต้อง ≥ 60% จึงผ่าน) · 💎 XP · 🔥 สตรีครายวัน · 🎙️ ภารกิจพูดประจำวัน
- 🎙️ ถอดเสียงพูด (Speech Recognition) + อัดเสียงฟังย้อน · 🔊 เสียงอ่านภาษาอังกฤษทุกประโยค
- 📓 สมุดงานเขียน + คลังข้อที่เคยผิด · 💾 ส่งออก/นำเข้าความคืบหน้า

## ติดตั้งบนมือถือ
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → *ติดตั้งแอป* / *เพิ่มลงในหน้าจอหลัก*
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*
- ต้องการไฟล์ **.apk**: นำลิงก์ไปใส่ที่ https://www.pwabuilder.com → Package for stores → Android

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าแอป |
| `data.js` | เนื้อหา 30 ด่าน (แก้ไข/เพิ่มคำถามได้ที่นี่) |
| `app.js` | ระบบเกม |
| `style.css` | หน้าตา (รองรับโหมดมืด) |
| `sw.js`, `manifest.webmanifest`, `icons/` | ทำให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ |

> เมื่อแก้ไขไฟล์แล้ว ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `eng30-v2`) เพื่อให้มือถือที่ติดตั้งแล้วโหลดเวอร์ชันใหม่
